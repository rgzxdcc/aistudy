# AI 学习路线图

> 目标：从 Python 出发，快速掌握到机器学习的实际使用能力。

## 学习阶段

### 模块 1 · Python 速通 `01_python_basics/`
针对有其他语言基础的学习者，快速覆盖 Python 特有且在 ML 中高频使用的特性：
- 数据结构：列表 / 元组 / 字典 / 集合
- 列表推导式、字典推导式
- 函数：默认参数、可变参数、关键字参数、Lambda
- 面向对象：类、继承、魔法方法
- 迭代器、生成器、装饰器
- 文件与异常处理、with 上下文管理
- 模块与包、虚拟环境

### 模块 2 · NumPy 数值计算 `02_numpy/`
机器学习底层计算的基础，所有数据都会变成"数组"：
- ndarray 的创建与属性
- 索引、切片、布尔索引、花式索引
- 广播机制（Broadcasting）
- 向量化运算与常用数学函数
- 线性代数运算（矩阵乘法、求逆等）

### 模块 3 · Pandas 数据处理 `03_pandas/`
真实数据清洗与分析的利器：
- Series 与 DataFrame
- 读取 / 保存 CSV、Excel
- 数据选择、过滤、排序
- 缺失值与重复值处理
- 分组聚合 groupby、合并 merge/concat
- 透视表与时间序列入门

### 模块 4 · Matplotlib 数据可视化 `04_matplotlib/`
用图表理解数据，是特征工程和结果展示的前提：
- 折线图、柱状图、散点图、直方图
- 子图 subplot、图例与样式
- （扩展）Seaborn 统计可视化

### 模块 5 · 机器学习实战 `05_ml_basics/`
使用 Scikit-learn 掌握 ML 的标准工作流：
- ML 通识：监督/无监督、训练集与测试集、过拟合与欠拟合
- 数据集划分、特征预处理（标准化、编码）
- 监督学习：线性回归、逻辑回归、KNN、决策树、随机森林
- 模型评估：准确率、精确率/召回率、混淆矩阵、MSE/R²
- 无监督学习：K-Means 聚类、降维 PCA
- 完整实战项目：鸢尾花分类 / 房价回归

### 模块 6 · 数据集 `06_datasets/`
存放练习用的小型数据集（CSV 等）。

- 文件命名：`NN_主题.py`，如 `01_数据结构.py`。
- 推荐使用虚拟环境隔离依赖。
