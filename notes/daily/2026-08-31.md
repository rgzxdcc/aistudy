## 卡点 + 解决
- 问题：venv 激活后 `pip install` 报 command not found
- 排查：看 `.venv/bin/` 没有 pip → 看 `pyvenv.cfg` 发现 `uv = 0.12.5` → 结论：uv 创建的 venv 默认不装 pip
- 解决：改用 `uv pip install --python <venv>/bin/python 包名`
- **教训：环境问题先看 pyvenv.cfg / `which python`，确认"这是谁的 venv"**
