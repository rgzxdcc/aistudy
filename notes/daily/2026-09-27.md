## 昨日复习

### 提问 1：在本章中，嵌入模型+逻辑回归的分类方式获得了0.85的F1分数，而零样本分类方式获得了0.78的F1分数。如果有标注数据，什么情况下会选择零样本分类？
1. 标注数据太少，易过拟合，不如零样本稳健
2. 类别经常变动，零样本只需要改标签文本，无需重训

### 提问 2：与BERT的掩蔽策略相比，掩码语言建模有何不同？这种预训练方式如何帮助模型在下游的文本分类任务中获得更好的性能？
1. 掩码语言建模会对连续词元做掩码，BERT 对单个词元掩码
2. 这种预训练迫使模型结合上下文推断被掩词的语义，从而习得语境化的稠密表示，迁移到分类时只需浅层适配

### 提问 3：假设你有一个包含100万条客户评论的数据集，但只有1000条带有标签的数据，请同时利用有标签和无标签的数据，结合表示模型和生成模型的优势，构建一个分类系统
1. 使用生成模型，将100万条数据集进行分类生成，使其输出结果类别与标签集对齐
2. 先用1000条标注评估生成模型伪标签的准确率，保留高置信度标签
3. 使用表示模型对组合的标签数据集进行文本分类

### 提问 4：有了强大的生成式大模型，嵌入模型还有什么用？（提示：推荐系统）
1. 嵌入模型更擅长语义理解层面的任务，能够精准捕捉文本嵌入向量间的相似度。可用于语义检索、文本去重、语义相似度计算、推荐系统等任务
2. 嵌入模型可预计算，检索成本远低于逐条调用 llm

### 提问 5：词袋法和文档嵌入在实现原理上有什么区别？词袋法是不是一无是处了？
1. 词袋法类似统计学概念，是统计文本序列在词表中出现的次数，来表征向量；文档嵌入是通过预训练后充分理解语义下生成的向量；两者对文本的理解程度上相差很大
2. 词袋法效率较高，可支持文本聚类主题建模中快速挑选合适关键词

### 提问 6：BERTopic中的c-TF-IDF与传统的TF-IDF有何不同？这种差异如何帮助改进主题表示的质量？
1. c-TF-IDF 计算每个聚类簇中的词频，不是单文档中的词频
2. 可更准确地计算每个词元在簇中的凸显程度，能够为每个簇生成准确的主题

### 提问 7：基于质心和基于密度的文本聚类算法有什么优缺点？
1. 基于质心优点：计算简单快捷，所有文本都能够聚类；缺点：需要知道最终主题数量，可能将离群点也合并进某些主题
2. 基于密度优点：能够挑选出离群点，聚类更准确；缺点：计算成本高

### 提问 8：在一个主题建模项目中，你发现生成的主题中有大量重叠的关键词，如何使用本章介绍的技术来提高主题之间的区分度？
1. 使用最大边际相关性（MMR），过滤冗余词，寻找具有差异性的关键词
2. 合并相似主题、调整 min_topic_size、更换嵌入模型

### 提问 9：针对翻译类、创意写作类、头脑风暴类任务，分别如何设置temperature和top_p？
1. 翻译：temperature设置低值、top_p设置高值
2. 创意写作：temperature设置高值，top_p设置高值
3. 头脑风暴：temperature设置高值，top_p设置高值

### 提问 10：一个专业的提示词模板由哪几部分构成？为什么提示词中需要描述角色定义？
1. 专业的提示词模板：角色定位、指令、上下文、受众、格式、语气、数据
2. 角色定义方便大模型知道它的定位以及提问者的定位，合理给出答案

### 提问 11：为了尽可能防止提示词注入，如何设计提示词模板？如何在系统层面检测提示词注入攻击？
1. 提示词层面：将用户输入视为数据而非指令、建立指令层级：系统提示优先于用户输入、限定输出格式
2. 系统层面：用小模型/规则做注入检测分类器、输入输出过滤、工具权限最小化、关键操作加人工确认

### 提问 12：在没有推理模型之前，如何让模型先思考后回答？思维链、自洽性、思维树等几种技术各有什么优缺点？
1. 可以在提示词中让模型进行链式回答（step by step），或给出推理示例
2. 思维链：可以引导模型按步骤或者示例进行分步思考，思考更充分；相对投入计算资源也更多
3. 自洽性：可以通过对同一套提示词进行多次提问，并对结果投票，能够选出更为合理的输出；缺点是需要多次调用大模型，成本较高
4. 思维树：将问题分多个步骤，每个步骤模拟专家打分，选出最优节点，能够输出可信度较高的内容；缺点是思维时间较长，生成速度较慢

### 提问 13：如何保证模型的输出一定是合法的JSON格式？将大模型用于分类任务时，如何保证其输出一定是几个类别之一，而不会输出无关内容？如果开发一个学习英语的应用，如何确保其输出的语言始终限定在指定的词汇表中？大模型的分词器和传统的中文分词有什么区别？对于指定的词表，一句话是不是只有唯一的分词方式？
1. 在提示词中明确输出格式为 JSON，对输出结果做 JSON 格式验证，校验失败自动重试
2. 分类任务用枚举校验+默认兜底
3. 在解码阶段约束采样，对超出词表范围的 id 进行处理，使其回到词汇表中
4. 中文分词器依赖字典+统计，是传统语言学上的分词；大模型分词器通过对语料库的字符组合，能够覆盖所有文本
5. 词表固定，BPE合并顺序确定，根据贪心切分，一句话分词也固定
