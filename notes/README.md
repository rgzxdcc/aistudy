# 学习笔记系统

> 原则：笔记写给三个月后去面试的自己看——他能看懂、能复述、能被追问，就合格。

## 三层结构

| 目录 | 放什么 | 篇幅 | 更新时机 |
|---|---|---|---|
| `daily/` | 日笔记：做了什么、卡点+解决、一句话收获 | 3–5 行 | 每天最后 30 分钟 |
| `topics/` | 主题笔记：用自己的话讲清概念 + 关键代码 | 半页~一页 | 每章/每主题结束当天 |
| `reviews/` | 项目复盘（面试直接引用的四份大文档） | 1–2 页 | 按计划节点 W4/W5/W8/W10 |

## 约定

1. 日笔记文件名 `YYYY-MM-DD.md`，写今天的日期，不补历史
2. 最值钱的内容是「卡点 + 解决过程」——面试问"遇到过什么困难"时，真实排查案例胜过背八股
3. 主题笔记的检验标准：合上资料能给别人讲明白
4. 每周日晚 5 分钟周检查后，顺手清掉本周笔记欠账；笔记欠账 = 进度欠账
5. 随代码一起提交：`git add . && git commit -m "notes: ..." && git push`
