# llm_app

### 1. 介绍

开始从基础的api服务生成，到调试、发布、Docker部署。  
到学习大语言模型原理，从零构建大模型（GPT），实现基础模型应用。  
最后实现两个经典应用：RAG+Agent
后续所做的提升：tbd

### 2. 模块

#### 2.1 FastAPI基础： 01_api_basics
1. 工程位于llm_app/01_api_basics目录下
2. 安装ollama、fastapi、uv等环境
3. 学习fastapi基础知识：环境安装、路径函数、查询函数、请求体、响应模型、错误处理、服务部署等
4. 完成脱稿手敲post输入请求体获取请求体输出流程
5. 完成fastapi模块输出：一个正式LLM服务。实现基础问答，本地模型问答，以及流式输出改进
6. 安装Docker环境，完成app.py的镜像制作，验证访问服务成功。并优化本地模型访问，实现在Docker中进行本地模型调用
7. 完成Sql课程1-12课学习，基本是查询语句以及关键词的复习回顾
8. 准备第二阶段学习环境，查看PyTorch安装情况，对齐版本要求

### 2.2 从零构建大模型：02_llm_from_scratch
1. 工程位于llm_app/02_llm_from_scratch目录下
2. 安装PyTorch环境，学习其提供的三大特性：张量、自动微分、深度学习配套工具，详见 pytorch_from_scratch.py
3. 学习分词器制作与使用。根据PyTorch框架，从数据集中采样，构建输入-目标对。创建嵌入层，将词元ID转为嵌入向量，并添加位置编码信息。详见embedding.py
4. 学习构建简单注意力机制。在此基础上，提升为缩放点积注意力。添加因果掩码，dropout策略，平衡模型学习权重。最终根据大矩阵的view与transpose，将单头注意力扩展为多头注意力，增加模型对上下文的理解能力。详见attention.py
5. 学习构建GPT框架，使用层归一化、多头注意力、前馈神经网络（使用GELU）、残差连接构建Transformer核心组件。搭配词元嵌入、位置嵌入、Dropout、层归一化、输出线性投影等完成手搓基础GPT大模型，且能够顺利生成文本（未经训练的结果）。详见model.py
