开始从基础的api服务生成，到调试、发布、Docker部署。

### 2. 模块

#### 2.1 FastAPI基础： 01_api_basics
1. 工程位于 llm_app/01_api_basics 目录下
2. 安装 ollama、fastapi、uv 等环境
3. 学习 fastapi 基础知识：环境安装、路径函数、查询函数、请求体、响应模型、错误处理、服务部署等
4. 完成脱稿手敲 post 输入请求体获取请求体输出流程
5. 完成 fastapi 模块输出：一个正式LLM服务。实现基础问答，本地模型问答，以及流式输出改进
6. 安装 Docker 环境，完成 app.py 的镜像制作，验证访问服务成功。并优化本地模型访问，实现在 Docker 中进行本地模型调用
7. 完成 Sql 课程 1-12 课学习，基本是查询语句以及关键词的复习回顾
8. 准备第二阶段学习环境，查看 PyTorch 安装情况，对齐版本要求

### 2.2 从零构建大模型：02_llm_from_scratch
1. 工程位于 llm_app/02_llm_from_scratch 目录下
2. 安装 PyTorch 环境，学习其提供的三大特性：张量、自动微分、深度学习配套工具，详见: pytorch.py
3. 学习分词器制作与使用。根据 PyTorch 框架，从数据集中采样，构建输入-目标对。创建嵌入层，将词元ID转为嵌入向量，并添加位置编码信息。详见: embedding.py
4. 学习构建简单注意力机制。在此基础上，提升为缩放点积注意力。添加因果掩码，dropout 策略，平衡模型学习权重。最终根据大矩阵的 view 与 transpose，将单头注意力扩展为多头注意力，增加模型对上下文的理解能力。详见: attention.py
5. 学习构建 GPT框架，使用层归一化、多头注意力、前馈神经网络（使用 GELU）、残差连接构建 Transformer 核心组件。搭配词元嵌入、位置嵌入、Dropout、层归一化、输出线性投影等完成手搓基础 GPT大模型，且能够顺利生成文本（未经训练的结果）。详见: model.py
6. 能够对 GPTModel 在小数据集上做预训练，并使用训练后的模型进行文本生成。能够调整生成策略，影响结果的确定性。详见: pre_train.py
7. 能够构建分类数据集，创建数据加载器。修改模型结构，构建分类微调训练循环。加载预训练权重，对模型进行微调。通过损失曲线以及准确率评估模型微调后，执行分类任务的能力。详见: classifier.py
8. 能够组织指令微调数据集，封装自定义聚合函数，创建数据加载器，进行微调训练。能够通过第三方大模型对模型的指令回复能力进行打分评判。详见： instruction.py
